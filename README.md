# ALRANQQY — alranqy.com

Static website for ALRANQQY, glass & aluminium installation and maintenance, Mai Tower, Al Nahda 1, Dubai.

- `index.html` — the whole page (HTML, CSS and JS inline). Services, projects and FAQs are edited in the `DATA` block at the top of the script.
- `assets/img/` — optimised photos and logo.

Deploy by uploading `index.html` and the `assets/` folder to the web root.
